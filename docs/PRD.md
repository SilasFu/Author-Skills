# Author-Skills 产品需求文档 (PRD)

## 1. 产品定位与愿景

`Author-Skills` 是个人 AI 工作区生态的**元治理与自进化母体技能库（Meta-Governance & Self-Evolution Engine）**。
它不提供琐碎的日常业务代码生成或界面美化工具（此类需求由公版社区 Skill 解决），而是专注于解决：
1. **机制建立（Establishment）**：在任何全新设备、单分区或跨平台环境下，一键拉通五大工作区拓扑；
2. **自我修正（Self-Correction）**：主动诊断项目架构腐烂、清理硬编码野样式与工具黑盒暗状态；
3. **自我改进（Self-Improvement）**：将对话中的用户纠偏与新偏好原子化提炼，回写权威知识库并 Git 固化，实现全生态跨设备永久免疫。

---

## 2. 目标用户与使用场景

- **场景 A（换机与重装系统）**：用户在新电脑上需要 1 分钟内无损恢复完整的五大工作区心智与 Agent 规则；
- **场景 B（新项目立项与防跑偏）**：在新建或导入的项目中一键植入防腐机制、200 行单文件限制、单一设计契约与编译器门禁；
- **场景 C（日常迭代与规则进化）**：用户指出 Agent 的设计或代码问题时，自动沉淀为永久规则，确保未来所有 Agent 不再犯同类错误。

---

## 3. 四大核心母体技能规格矩阵

| 技能标识 | 核心定位 | 输入与触发 | 输出与交付物 | 非目标 (Non-Goals) |
| :--- | :--- | :--- | :--- | :--- |
| **`workspace-bootstrap`** | 全生态冷启动与自举 | `/workspace-bootstrap init` 或在新环境首次配置 | 自动绑定私有库、生成自感知环境变量、多 Agent 软链接挂载 | 不承担具体项目内部业务代码编写 |
| **`project-guard`** | 项目守护、体检与规则自进化 | `/project-guard init` / `doctor` / `evolve` | 项目级 `AGENTS.md`、单文件拆分重构、规则回写 Git 提交 | 不替代具体框架的脚手架生成工具 |
| **`workspace-lifecycle-governance`** | 跨工作区流转与决策引擎 | 知识缺口感知、新立项诉求、架构决策变更 | `My_Learning` 缺口卡片、复用阶梯决策报告、`MY_Memories` 索引同步 | 不直接编写业务学习文章本身 |
| **`my-memories`** | 权威记忆库查询接口 | 查询画像、偏好、协作边界、架构规范 | 权威 Markdown 上下文切片 | 不作为写入通道（写入由 governance 承担） |

---

## 4. 核心非功能性要求 (NFR)

1. **零硬编码与隐私安全**：源码中 100% 杜绝个人姓名、私密路径与特定 GitHub 账号，所有私有资产通过运行时动态自适应绑定；
2. **跨平台与单分区自适应**：全面支持 Windows（C/D 盘）、Mac、Linux 等任意环境，消除盘符硬编码依赖；
3. **高信噪比与防早退**：每个 SOP 必须包含清晰可检验的完成标准（Checkable Bounds）。
