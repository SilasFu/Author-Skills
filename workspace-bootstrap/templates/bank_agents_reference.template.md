# Reference_Coding 外部参考库治理规约 (AGENTS.md)

## 1. 工作区定位与职责边界

本目录为个人开发生态的 **外部开源与对标参考库 (Reference Bank)**。
- **核心职能**：存放从 GitHub 等开源社区克隆的高质量第三方开源项目，用于只读研读、架构参考与技术对标；
- **核心定位**：**严格只读 (Strictly Readonly)**。

---

## 2. 核心行为准则与红线 (Do's and Don'ts)

### 2.1 严厉禁止 (Don'ts)
- ❌ **绝对严禁在此进行自研生产业务开发**：自研代码必须在 `Vibe_Coding/` 开发；
- ❌ **严禁修改或提交外部开源仓库源码**：除非参与上游开源 PR，否则本地代码保持原汁原味；
- ❌ **严禁把未修改的外部库混入 `Vibe_Coding` 或 `Author-Skills`**。

### 2.2 推荐实践 (Do's)
- ✅ 研读外部架构与实现模式，将学到的优秀实践抽象总结至 `My_Learning/` 或提炼为 `Author-Skills/` 中的通用机制；
- ✅ 建议在每个克隆的参考库根目录保持 `.git` 干净以便后续 `git pull` 同步上游。
